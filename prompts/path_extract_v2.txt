You extract REAL attack / reconnaissance BEHAVIOR UNITS from ONE CHUNK of a pentest writeup.

============================================================
CORE: behavioral steps, NOT HTTP log lines
============================================================
A Step = one human-understandable attack/recon INTENT that may span multiple requests.

WRONG (request-level shredding):
- Step1 GET /
- Step2 GET /robots.txt
- Step3 GET /sitemap.xml
- Step4 GET /javascript/

RIGHT (same intent → one step):
- Step: 对 Web 应用进行路径/资源探测（含 /, robots.txt, sitemap 等）
  evidence: list the raw requests

Split ONLY when attack INTENT changes (recon → login → exploit → lateral, etc.).

============================================================
Observed vs concluded (critical)
============================================================
- action MUST NOT exceed what evidence supports (information content of action ≤ evidence).
- HTTP 200 alone ≠ "成功利用 IDOR / 获取其他用户数据 / 管理员权限".
- Login 302 alone ≠ "获得管理员权限".
- Prefer: "请求 … 返回 200" over unproven "成功越权".
- Do NOT back-propagate later flag/SYSTEM success into earlier steps.
- If writeup only shows observation, set step_type=observation (not attack).

============================================================
step_type (classification ONLY — never used alone for ATT&CK)
============================================================
attack | reconnaissance | credential_access | exploitation | execution |
persistence | defense_evasion | lateral_movement | collection | discovery |
tool_setup | data_processing | validation | observation | other

- git clone / pip / go build / venv / download wordlist → tool_setup
- CSV→JSON / pretty-print / save logs → data_processing
- view response / check status / open page without clear attack intent → observation
- port/path enum with scan tools or batch probing → reconnaissance
- exploit / RCE with effect → exploitation

phase (Chinese, only if justified by THIS step):
侦察 | 账户/凭据获取 | 初始访问 | 执行 | 权限提升 | 持久化 | 防御规避 |
发现 | 横向移动 | 收集 | 命令与控制 | 其他

============================================================
Other rules
============================================================
- Only actions actually performed in THIS chunk.
- Do NOT invent steps to complete a chain.
- evidence_type=mentioned → do NOT emit the step.
- action = short Chinese behavioral description; commands go in evidence.
- Keep strings short. Max max_steps per chunk.
- Empty chunk → {"steps":[],"edges":[]}
